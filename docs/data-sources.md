# Источники данных для радара

Справочник: что откуда можно брать, сколько стоит и что уже подключено.
Состояние на 20.10.2026. Цены и лимиты сторонних сервисов меняются — перед
покупкой сверяйте на их сайтах.

## Подключено

| Источник | Что даёт радару | Доступ | Где в коде |
| --- | --- | --- | --- |
| **Checko** (api.checko.ru) | ЕГРЮЛ: директор, учредители, капитал, ОКВЭД, филиалы, статус; реестр МСП; Федресурс (залоги, намерения о банкротстве; свежего лизинга нет — проверено); ЕФРСБ; ФССП; отчётность ГИР БО за годы; заключённые госконтракты 44-ФЗ и 223-ФЗ | Ключ `CHECKO_API_KEY`. Бесплатно — 100 запросов в день (~55 компаний), платный тариф — без такого лимита | `kmradar/checko.py` |
| **RSS и Telegram** | Новости о компаниях базы | Бесплатно, без ключей. Список — `/var/lib/kmradar/feeds.txt` (стартовый — `deploy/feeds.txt`) | `kmradar/news.py` |
| **Ручной ввод аналитика** | Любой повод с фактами и ссылкой на источник | Админ-ссылка `kmradar admin-link` | `kmradar/admin.py` |

## Можно подключить: бесплатно

| Источник | Что даёт | Ограничения |
| --- | --- | --- |
| **ЕИС, сервис отдачи информации** (zakupki.gov.ru) | **Протоколы итогов закупок** — самый сильный сигнал «победа в закупке» до подписания контракта; поиск победителей по региону; реестр банковских гарантий; реестр недобросовестных поставщиков; исполнение контрактов | Токен физлица через zakupki.gov.ru/pmd (вход через Госуслуги). Страница требует ГОСТ-шифрование: Windows + Яндекс Браузер + КриптоПро CSP. С планшета не получить |
| **Поиск на zakupki.gov.ru** | То же, но руками | Без входа. Для ручного режима: 44-ФЗ → «Закупка завершена» → регион → цена от 10 млн |
| **DaData** (dadata.ru) | Карточка компании по ИНН: статус, руководитель, ОКВЭД, адрес, филиалы | Бесплатный тариф с дневным лимитом (по памяти — около 10 000 запросов; проверить). Может взять на себя ежедневную проверку директоров и статусов вместо Checko |
| **Открытые данные ФНС** (nalog.gov.ru/opendata) | Реестр МСП (категория, ОКВЭД, регион) — список компаний территории; доходы и расходы; среднесписочная численность; налоговые режимы | Файлы XML, обновления раз в месяц или год. Без API — скачивать архивы |
| **hh.ru API** | Вакансии компании: рост найма → повод для зарплатного проекта | Проверить, нужен ли ключ приложения |
| **Реестр Росаккредитации** (pub.fsa.gov.ru) | Сертификаты и декларации ЕАЭС: новый продукт, импорт | Открытый поиск, API неофициальный |

## Можно подключить: платно

| Источник | Что даёт | Комментарий |
| --- | --- | --- |
| **Контур.Фокус API** | Почти всё одним сервисом: ЕГРЮЛ, арбитраж, Федресурс с лизингом, закупки, ФССП, отчётность | Дорого. Часто уже куплен в банке — кандидат для внутрибанковской версии |
| **СПАРК-Интерфакс** | Аналогично Фокусу, плюс аналитика рисков | То же: в банках обычно есть лицензия |
| **Контур.Закупки, Тендерплан, Seldon** | Протоколы и результаты закупок по API | Замена токена ЕИС. Цены уточнять |
| **Яндекс Поиск API** (Yandex Cloud) | Поиск новостей о компании по названию | Оплата за запросы |
| **Медиалогия, Интегрум** | Мониторинг СМИ по компаниям | Дорого, корпоративные лицензии |

## Только руками (без API)

| Источник | Что даёт | Почему не автоматизируем |
| --- | --- | --- |
| kad.arbitr.ru | Арбитражные дела | Капча; обход защиты — серая зона (ст. 272 УК) |
| fssp.gov.ru | Исполнительные производства | Капча. Долги уже есть в Checko |
| egrul.nalog.ru | Выписка ЕГРЮЛ по одной компании | По одной, с защитой от массовых запросов |
| bo.nalog.gov.ru | Отчётность по одной компании | Нет официального API. Отчётность уже есть в Checko |
| fedresurs.ru | Договоры лизинга, залоги | Официальный API платный, для партнёров. Свежего лизинга в Checko нет |

## Что дальше (рекомендация)

1. **Ручной режим + Checko** — уже работает, этого хватает для проверки гипотезы на пилоте.
2. **Токен ЕИС** — с компьютера на Windows; даст срочные карточки о победах и сам соберёт территорию.
3. **DaData** — разгрузит бесплатный лимит Checko на ежедневных проверках.
4. **Реестр МСП ФНС** — автоматический список компаний территории по региону и ОКВЭД.
5. Для версии внутри банка — **СПАРК или Фокус**, которые, скорее всего, уже есть.
